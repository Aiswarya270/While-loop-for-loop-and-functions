# While-loop-for-loop-and-functions
Python assignment covering while loops, for loops, control statements, and functions.

This assignment is based on Python while loops, for loops, and functions.

## Topics Covered

- While Loop
- For Loop
- Control Statements
  - break
  - continue
  - else
- Functions
- random and randint()

## Programs Included

### 1. Number Guessing Game
A simple guessing game where the user has 3 attempts to guess a random number between 1 and 10.

### 2. Multiplication Table
A program that takes a number from the user and prints its multiplication table from 1 to 10.

### 3. BMI Calculator
A simple BMI calculator using a Python function. The user enters their weight and height, and the program calculates the BMI.

## Language Used

- Python

## Purpose

This assignment helped me practice Python loops, control statements, functions, user input, and basic calculations.
